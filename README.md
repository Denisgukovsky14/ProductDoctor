Данное приложение является результатом моей работы с Фреймворком для разработки мобильных приложенией на языке C# .NET MAUI. Мной было разработно мобильное приложение для сканирования штрихкодов и нахождения их в базе данных, после чего пользователь получает все возможные данные о продукте, в том числе пищевую ценность, описание каждого ингридиента и отзывы других покупателей, рекомендации похожих продуктов
