# Мой продукт

**Мобильное приложение на .NET MAUI: наводишь камеру на штрихкод — получаешь всё о продукте.**

Зачем: в составе продуктов полно непонятных среднестатистическому гражданину ингредиентов, а у товаров на полке нет отзывов. ProductDoctor или же My product за пару секунд показывает, что внутри, насколько это безопасно и что взять вместо.

## Как это работает

1. **Сканирование** — камера распознаёт штрихкод EAN-13 (ZXing).
2. **Поиск** — по коду находится продукт в базе данных.
3. **Карточка продукта:**
   - состав, где потенциально опасные ингредиенты подсвечены красным; по нажатию открывается описание добавки;
   - пищевая ценность на 100 г (белки, жиры, углеводы, ккал);
   - рейтинг «Роскачества» с пояснением оценки;
   - рекомендации — товары той же категории с оценкой 4–5;
   - отзывы покупателей и форма, чтобы оставить свой.
4. **Новости** — отдельная лента о товарах и качестве продуктов.

## Технологический стек

| | |
|---|---|
| Платформа | .NET 8, **.NET MAUI** (Android, iOS, macOS, Windows) |
| Архитектура | **MVVM**: CommunityToolkit.Mvvm, Refractored.MvvmHelpers |

## Данные и масштабирование

Сейчас приложение работает на **пробной локальной базе** (`Resources/Raw/ProductDataBase.db`): 11 продуктов из 5 категорий (колбаса, майонез, масло, сосиски, сыр). Для проверки можно отсканировать, например:

`4607091385731` — сосиски «Вязанка Молочные» · `4810268035265` — сыр «Брест-Литовск» · `4604248000844` — майонез «Махеев»

Весь доступ к данным сосредоточен в одном слое — `Services/CompositionService`. Страницы и ViewModel не знают, откуда берутся данные, поэтому **проект готов к масштабированию**: для перехода на онлайн-базу (REST API / облачная БД) достаточно заменить реализацию сервиса, не трогая интерфейс приложения. Это откроет полный каталог товаров и общие отзывы между пользователями.

## Запуск

1. Visual Studio 2022 с нагрузкой **.NET MAUI**.
2. Открыть `Barcoding.sln`, выбрать Android-эмулятор или Android устройство.
3. Запустить. Для сканирования нужна камера.
